# Diplomatic Latin

No diplomatic transcription is committed here until the corresponding manuscript image or critical-edition witness is available to the project. Use the records in `../manuscripts/catalog.json` to open a transcription task.

Required file header:

```text
Witness: <catalog id>
Locator: <archive shelfmark and folio/page>
Transcriber: <name>
Date: <YYYY-MM-DD>
Policy: diplomatic | normalized
```
