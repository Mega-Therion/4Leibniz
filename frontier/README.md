# Layer 3 — Frontier extensions

The frontier layer contains modern RYTT constructions that interpret, extend, or test the formal kernel. `rytt_geometric_calculus.py` is deliberately dependency-free so the kernel remains buildable without the RYTT repository.

Every interpretation records the Lean theorem identifiers it extends. Balanced ternary, base-24 holonomy, and the `SO(5)/SO(3)` Stiefel-coset label are modern extension data; they are not asserted to be statements written by Leibniz.
